# Agent-waiting flags in tmux window pills

**Date:** 2026-11-12 · **Status:** approved

## Intent

When a Claude Code session in some tmux window is waiting on Jason, its
window pill should say so — he loses track of which window has an agent
blocked on him when working across several windows. The flag must clear
the moment he responds, not merely when he visits the window.

## Goals

- Per-window indicator: "blocked on permission/input" vs "finished a turn,
  idle" states are visually distinct.
- Event-driven: no polling, no `status-interval` dependency.
- Degrades silently when Claude runs outside tmux.

## Non-goals

- Cost/usage display, desktop notifications, per-pane granularity.

## Anti-goals

- A flag that can't be trusted (false positives/negatives) — that was the
  reason to reject the bell approach.

## Constraints

- Claude Code config (`settings.json`, `hooks/`) lives in the separate
  `local-config` repo, symlinked into `~/.claude` by `modules/dotfiles.nix`.
- tmux theme/config lives in this repo (`tmux/tmux.conf`), regenerated by
  `make hm` and reloaded with `<prefix> r`.
- Commits need Jason's terminal (YubiKey-signed).

## Approaches considered

1. **Terminal bell + `monitor-bell`** — config-only, but any program's bell
   triggers it, can't distinguish states, and clears on window *visit*.
2. **Claude Code hooks → tmux window option** (picked) — precise, two
   distinguishable states, clears on prompt submit.

## Design

- One script, `local-config/hooks/tmux-agent-flag.sh`, registered for seven
  hook events in `settings.json` (grew from four in review: a notification-type
  matcher keeps idle_prompt from flipping ● back to ✋, and PostToolUse +
  PostToolUseFailure clear a granted-permission ✋):
  - `Notification` (matcher: permission/input types only) → `tmux set -w -t
    "$TMUX_PANE" @claude_waiting ask`
  - `Stop` → `@claude_waiting done`
  - `UserPromptSubmit`, `SessionEnd`, `PostToolUse`, `PostToolUseFailure` →
    unset the option
  - `$TMUX_PANE` is inherited from the Claude process; empty → exit 0.
- `window-status-format` / `window-status-current-format` in
  `tmux/tmux.conf` gain a conditional segment: orange `✋` on the pill when
  `@claude_waiting=ask`, calmer `●` when `done`.
- Setting a window option redraws the status line immediately.

## Accepted edges

- Two Claude panes in one window share one flag; last writer wins.
- A hard-killed Claude can leave a stale flag until the next event or
  window close.

## Left to the builder

Exact glyphs/colours within the existing gruvbox palette; exact tmux format
conditional syntax; hook matcher specifics.
