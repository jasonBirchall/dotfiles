# Fedora system packages. See ubuntu/system-packages.txt for the apt counterpart.

# Moved to Nix (modules/packages.nix), so absent here and pinned to identical
# versions on every distro: lnav, wl-clipboard, playerctl, wev, pop-launcher.
#
# ghostty is NOT among them. The nixpkgs build cannot create an EGL display on
# a non-NixOS host — it links Nix's libEGL, which searches the store for
# drivers instead of the distro's /usr/lib — so it starts and exits. GPU-backed
# GUI apps stay in the distro layer; CLI tools above are unaffected.
# brightnessctl deliberately stays below — this package ships
# 90-brightnessctl.rules, and Nix cannot install a udev rule that a non-NixOS
# udev will read.
